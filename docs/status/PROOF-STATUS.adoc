== Scope of those results — read this before quoting them

Green above means *the kernel path*: exactly one demonstrated dial point (the
FFI-adjacent, in-process point, 2026-07-09). It is not the full surface.
Per `docs/PROOF-NEEDS.adoc`:

* `O-1`..`O-5`, `O-9`, `G-1`, `G-7` — closed *for the kernel path only*.
* `O-6` (joint completion, RC-9) and `O-7` (clean-XOR-rupture, RC-13 general)
  — open: they need two peers and a wire, neither of which exists yet.
* `O-8`/`G-5` — partial: groove's provider/CLI signing legs are in; the
  gossamer verify leg and burble producer-signing leg are not.
* `G-4` — open: RC-1..13 are vacuously green outside the kernel, because no
  real Hard-owns-Soft owns-graph exists in any consumer yet.
* `G-2`/`G-3` gossamer legs — *CLOSED, machine-verified 2026-08-03*: the
  designated CI (gossamer `e2e.yml`), repaired in gossamer#137 and unblocked by
  the #143 FFI fix, ran green on gossamer `main` @ `5da3f63` — `E2E + Safety`
  run 30842887080, `ABI Typecheck Gate` run 30842887323. See those rows in
  PROOF-NEEDS for the full trail.

The bar for "demonstrated" is unchanged: real capability, soft *and* hard,
descent actually invoked, handle actually linear, proof guarding running code.
One point meets it. Saying "one point, no further" is the method.
